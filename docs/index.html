🌍 Pondlife Simulator

Game of Life / Ecosystem Evolution Preview

About

This is a Processing IDE sketch that simulates an evolving ecosystem with "herbivores" and "predators", nutrient fields, scent diffusion, and interactive controls. Watch as the ecosystem evolves and adapts in real-time!

Interactive Controls

LEFT Click Paint nutrients (adds food)
RIGHT Click Shockwave / repel
SHIFT + LEFT Shockwave / repel
G Toggle overlays
F Toggle animated flow
X Toggle fullscreen
E Toggle evolution (splitting)
1 Spawn herbivores at mouse
2 Spawn predators at mouse
C Clear all agents & fields

Get Started

Want to run this yourself? Install Processing and open the Game_of_life_processing_V2.pde file from the repository!
